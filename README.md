# Holberton School Web Front-End 🎨

This repository contains various projects focused on front-end web development, covering advanced HTML and CSS concepts. Each folder represents a different project designed to master the fundamentals of modern web design and user interface development.

## Projects Overview 📚

### [HTML Advanced](./html_advanced) 📄
A project focused on creating a website using only HTML, exploring:
- Semantic HTML5 elements
- Building a structured webpage from scratch
- Creating complex layouts with HTML
- Best practices for page organization
- Accessibility considerations
- SEO-friendly markup

### [CSS Advanced](./CSS_advanced) 🌈
A comprehensive exploration of advanced CSS techniques, including:
- CSS selectors and specificity
- Box model and layout techniques
- Responsive design principles
- CSS variables and custom properties
- Animations and transitions
- Flexbox and Grid layouts
- Advanced styling features

## Technologies Used 💻
- HTML5
- CSS3
- Git
- Visual Studio Code (or your preferred editor)
- Web browsers for testing and visualization

## Learning Objectives 🎯
- Build semantically structured HTML pages
- Create visually appealing interfaces with advanced CSS
- Implement responsive designs for various screen sizes
- Follow best practices for web accessibility
- Optimize front-end code for performance
- Understand the principles of modern UI/UX design
