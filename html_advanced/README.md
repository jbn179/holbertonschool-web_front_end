# HTML Advanced 📄

This project focuses on building a complete webpage from scratch using pure HTML, without CSS or JavaScript. The goal is to create a semantically correct and well-structured markup that forms the foundation of a modern website.

## Project Overview 📋

The project consists of implementing a webpage from a designer file, progressively building different sections:

- **Header & Navigation**: Structure of site header and main navigation
- **Main Content Sections**: Hero, Services, Works, About, Latest News, Testimonials
- **Footer**: Contact information and site links
- **Special Pages**: About, Latest News, Article pages
- **Developer Tools**: Style guide, reusable components

## Key Concepts ✨

- **Semantic HTML5**: Using appropriate elements (header, nav, section, article, etc.)
- **Accessibility**: Ensuring content is accessible with proper ARIA attributes
- **SEO Optimization**: Using structured data and proper heading hierarchy
- **Forms & Inputs**: Creating interactive elements like contact forms
- **Media Integration**: Embedding images and videos properly
- **HTML Validation**: Ensuring code meets W3C standards

## File Structure 📁

- **index.html**: Main landing page of the website
- **about.html**: Information about the company/team
- **latest_news.html**: Blog or news section
- **article.html**: Individual article template
- **styleguide.html**: Reference for HTML elements used throughout the project
- **images/**: Directory containing all image assets
- **favicon.ico/png**: Site favicon in different formats

## Learning Objectives 🎯

- Create a fully structured HTML webpage from scratch
- Understand HTML5 semantic elements and their proper usage
- Implement SEO best practices in HTML markup
- Structure content in a logical and accessible way
- Prepare HTML for future styling with CSS
- Follow industry standards for code organization

## Requirements ⚙️

- All HTML should be valid and pass the W3C validator
- All files should end with a new line
- Double quotes should be used for attribute values
- Code should be properly indented
- No CSS or JavaScript allowed in this phase
- HTML comments should be used to describe sections

## Usage 🛠️

Open any HTML file in a web browser to view the raw structure:

```bash
# For example, to view the main page in Firefox
firefox index.html
```

## Validation 🔍

You can validate your HTML using the provided validator script:

```bash
./w3c_validator.py index.html
```
